# Linear3D

使用 Bevy 展示三元一次方程的三个平面，以及克拉默法则的逐步计算。

运行：`cargo run`。发布构建：`cargo build --release`。

输入 12 个系数后点击 **Apply** 更新场景；编辑草稿不会改变当前演示。**Reset** 恢复默认方程。

计算演示依次显示 A → D → Ax/Dx → Ay/Dy → Az/Dz → 坐标：

- **Play / Pause**：播放或暂停。行列式的六项乘积依次高亮，每项一秒；高亮同步到矩阵元素。
- **Previous / Next**：前后切换步骤，同时暂停并重置该步骤的动画进度。
- **Restart**：回到第一步并暂停；播放结束后点击 **Play** 可重新播放。
- **Slower / Faster**：调整播放速度，范围为 0.25–4 倍。

替换列以背景色标出；当前乘积以金色高亮，同时显示累计和及最终行列式。最后一步展示 `x=Dx/D`、`y=Dy/D`、`z=Dz/D` 和交点坐标。切换计算步骤不会移动原方程对应的平面，场景相机仍使用原有轨道控制。

默认样例的 D、Dx、Dy、Dz 分别为 7、7、14、21，交点为 (1, 2, 3)。三个平面依次为紫红、蓝、绿，金色点表示共同交点。

应用或重置会停止并清空旧播放。无解、无数解或无法安全计算有限交点时，程序继续运行，隐藏旧交点、禁用演示，不弹出提示；仍可修改方程或操作相机。零法向量对应的平面隐藏，恢复有效方程后重新显示。
